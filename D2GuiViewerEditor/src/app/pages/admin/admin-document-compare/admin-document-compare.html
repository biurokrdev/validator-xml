Jeden wiersz = jedna przyczyna, np. „433× Zapis dodał: w:rFonts”. Licznik po lewej to liczba miejsc w pliku, tytuł mówi, co się stało, szara linia pod nim wyjaśnia dlaczego, a plakietki: gdzie (część pakietu), skutek dla dokumentu i kto zawinił (nasz pipeline / użytkownik / Word).

Klik w wiersz rozwija wystąpienia: akapit, w którym to jest, wartości „było → jest” (czerwone przekreślone = oryginał, zielone = po zapisie), ścieżki XML i wycinek obu plików obok siebie.

Kubełki u góry: „Do naprawy u nas” = lista zadań dla programisty (przy każdym „kod:” mówi, gdzie zacząć); „Do sprawdzenia” = przejrzyj z kontekstem akapitu, czy użytkownik to zmienił celowo; „Nieistotne” = szum, nie trać na to czasu.
